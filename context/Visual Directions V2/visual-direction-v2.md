## Cara pakai (untuk dev / agent)

1. Baca `Moodboard.md` dulu untuk token warna, font, dan logo. Setup ini dipakai di semua section.
2. Bangun per section mengikuti `Storyboard.md` §2, urut 01 → 11. Cek sambungannya di §3.
3. Untuk tiap section, buka link referensi di `Moodboard.md` §6 (juga ada di sticky note Moodboard Layout, bagian "LINKS").
4. Kalau ada perbedaan, yang dipakai adalah **Figma**, lalu `Storyboard.md` / `Moodboard.md`, baru dokumen ini.

Storyboard 3 (Tools & stack) di Figma sengaja tidak dimasukkan ke dokumen; teknis implementasi diserahkan ke dev.
